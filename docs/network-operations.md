# Network Operations

Swift manages libvirt virtual networks. All network commands connect to the system libvirt daemon (`qemu:///system`).

Network commands are accessed via `swift network` or the `swift net` alias.

## network create

Creates and defines a new virtual network.

### Flags

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--cidr` | | (required for non-bridge) | CIDR for the network (e.g. 192.168.122.0/24) |
| `--mode` | `-m` | nat | Forward mode: nat, route, bridge, macvtap, passthrough, isolated |
| `--bridge` | | | Bridge device name |
| `--device` | `-d` | | Host device for forwarding |
| `--dhcp` | | false | Enable DHCP on the network |
| `--dhcp-start` | | | DHCP range start IP |
| `--dhcp-end` | | | DHCP range end IP |
| `--file` | `-f` | | YAML configuration file |

### Forward modes

| Mode | Description |
|------|-------------|
| `nat` | NAT network with optional DHCP (default) |
| `isolated` | Isolated network, no external access |
| `route` | Routed network without NAT |
| `bridge` | Attach to an existing bridge |
| `macvtap` | Direct attach via macvtap |
| `passthrough` | SR-IOV passthrough |

### Examples

```bash
# NAT network with DHCP
swift network create mynet --cidr 192.168.100.0/24 --dhcp

# Isolated network without DHCP
swift network create isolated --mode isolated --cidr 10.10.10.0/24

# NAT with custom DHCP range
swift network create mynet --cidr 192.168.100.0/24 --dhcp --dhcp-start 192.168.100.100 --dhcp-end 192.168.100.200

# Bridge mode
swift network create brnet --mode bridge --bridge br0

# From YAML config
swift network create mynet -f network.yaml

# Recreate from YAML round-trip
swift network create -f <(swift network show mynet -o yaml)
```

### DHCP

When `--dhcp` is enabled without specifying a range, Swift uses the full available range in the subnet (excluding the gateway address). With a /24 network at `.1`, DHCP serves from `.2` to `.254`.

To specify a custom range:

```bash
swift network create mynet --cidr 192.168.100.0/24 --dhcp --dhcp-start 192.168.100.50 --dhcp-end 192.168.100.100
```

## network list

Lists all defined virtual networks with their UUID, state, bridge, and forward mode.

```bash
swift network list
swift net list
swift nets list
```

Output:

```
NAME                 UUID                                   STATE        BRIDGE               MODE
----                 ----                                   -----        ------               ----
default              2c4ce08f-caa9-42e8-a5f2-9ff9d8ce9237   Active       virbr0               nat
mynet                3d5ef19g-dbaf-53f9-b6g3-agg0e9df348    Inactive     virbr1               nat
```

## network start

Activates a defined virtual network.

```bash
swift network start mynet
swift net start mynet
```

## network stop

Deactivates a running virtual network.

```bash
swift network stop mynet
swift net stop mynet
swift net down mynet     # alias
```

## network delete

Undefines a virtual network from libvirt.

```bash
swift network delete mynet
swift net delete mynet
```

## network status

Shows the state of a virtual network.

```bash
swift network status mynet
swift net status mynet
```

States: `Active`, `Inactive`

## network show

Displays the definition of a virtual network. Defaults to YAML format; use `-o xml` for raw libvirt XML.

```bash
swift network show mynet              # YAML (default)
swift network show mynet -o yaml      # explicit YAML
swift network show mynet -o xml       # raw libvirt XML
swift net show mynet                  # alias
```

### YAML output format

```yaml
network:
    name: mynet
    uuid: 3d5ef19g-dbaf-53f9-b6g3-agg0e9df348
    forward:
        '@mode': nat
    bridge:
        '@name': virbr1
        '@stp': "on"
        '@delay': "0"
    ip:
        '@address': 192.168.100.1
        '@netmask': 255.255.255.0
        dhcp:
            range:
                '@start': 192.168.100.2
                '@end': 192.168.100.254
```

## YAML configuration

### Simplified format

```yaml
name: mynet
cidr: 192.168.100.0/24
mode: nat
dhcp: true
dhcp_start: 192.168.100.100
dhcp_end: 192.168.100.200
```

### XML-mirroring format

Generated by `swift network show -o yaml`. Can be edited and fed back to `swift network create -f`:

```yaml
network:
    name: mynet
    forward:
        '@mode': nat
    bridge:
        '@name': virbr1
        '@stp': "on"
        '@delay': "0"
    ip:
        '@address': 192.168.100.1
        '@netmask': 255.255.255.0
```

## CIDR to netmask mapping

Swift automatically calculates the correct netmask from CIDR notation:

| CIDR | Netmask |
|------|---------|
| /24 | 255.255.255.0 |
| /16 | 255.255.0.0 |
| /8 | 255.0.0.0 |
| /28 | 255.255.255.240 |

## Default network

Most libvirt installations include a `default` network (NAT, 192.168.122.0/24, DHCP). Swift uses this as the default when no `--network` flag is specified during VM creation.

```bash
# Check default network status
swift network status default

# Start it if inactive
swift network start default
```
